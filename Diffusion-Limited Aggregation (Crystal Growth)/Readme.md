## 📌 About The Project

Diffusion-Limited Aggregation (DLA) simulates particles that move in random walks until they touch a growing cluster and stick. The result looks like frost, coral, or lightning.

---

## 🧠 Core Concepts

- Random walks
- Emergence of fractal structure
- How pure randomness can create order
- Natural pattern formation

---

## 🛠️ Tech Stack

- HTML + JavaScript + Canvas
- Simple physics (random movement + sticky collision)

---

## 🏗️ How to Build It

1. Create a sticky seed in the center (or bottom)
2. Spawn particles at the edges
3. Move each particle randomly
4. When a particle touches the cluster, freeze it
5. Repeat until the crystal grows
6. Add color based on age or distance
