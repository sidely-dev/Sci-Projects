## 📌 About This Repository

**Sci-Projects** is my personal laboratory for turning scientific and mathematical ideas into working programs.

The process is simple:

1. I read a book, paper, or article about something interesting  
2. I research whether the idea can be simulated or visualized in code  
3. I build a program version of it using whatever tech stack fits best  
4. I document what I learned

The goal is not just to make cool demos — it is to **deepen my understanding** of both the science and the programming required to bring it to life.

---

## 🧠 Philosophy

- Learn by building
- Prefer simple, clear implementations over complex frameworks (when possible)
- Make concepts visual and interactive whenever it helps understanding
- Treat every project as both a learning exercise and a portfolio piece
- Stay curious — any interesting idea is fair game

## 🛠️ Typical Tech Stack

Most projects start simple and stay lightweight:

- **HTML + CSS + JavaScript**
- **HTML5 Canvas** (for visualizations and simulations)
- Occasionally: p5.js, WebGL, or other tools when needed

I’m always open to learning new tools if the project requires them.

## 📖 How I Approach a New Project
``` text
1. Find an interesting scientific or mathematical idea
2. Research the core rules / equations
3. Decide on the simplest way to visualize or simulate it
4. Build a working version
5. Add interactivity (sliders, resets, comparisons)
6. Write a clear README explaining the concept and what I learned
```
